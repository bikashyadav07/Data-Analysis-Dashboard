# Excel Data Analysis Project – Bike Buyers Dataset

## Project Overview

This project focuses on analyzing customer data using Microsoft Excel to identify patterns and factors influencing bike purchases. The dataset contains demographic and customer-related information such as income, occupation, education, age, commute distance, and purchasing behavior.

The main objective of this project is to perform data cleaning, analysis, and visualization to derive meaningful business insights and present them through an interactive dashboard.

## Tools & Techniques Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Data Cleaning
* Conditional Formatting
* Dashboard Design
* Excel Functions & Formulas

## Key Analysis Performed

* Customer income analysis
* Age group and purchase behavior analysis
* Occupation-based customer segmentation
* Regional purchase comparison
* Commute distance impact on bike purchases

## Dashboard Features

* Interactive charts and visualizations
* Purchase trend analysis
* Demographic breakdown
* User-friendly dashboard layout

## Key Insights

* Customers with higher income showed higher bike purchase rates
* Middle-aged customers were more likely to purchase bikes
* Occupation and commute distance influenced customer decisions
* Regional differences affected purchasing behavior
